# 모션 메이커

이미지 한 장을 움직이는 이미지(APNG / WebP / GIF)로 만드는 웹 도구입니다.

**모든 처리가 브라우저 안에서 끝납니다.** 이미지가 서버로 올라가지 않습니다.

## 쓰는 법

1. 이미지를 끌어다 놓거나 붙여넣습니다 (Ctrl+V)
2. 왼쪽에서 움직임을 고릅니다
3. 내보내기를 누릅니다

시작 화면은 **PRO** 입니다. 레이어와 타임라인을 바로 만질 수 있습니다.
프리셋을 고르고 세기/속도 슬라이더만 쓰고 싶으면 위쪽 `EASY` 를 누르세요.

## 특징

- 모션 프리셋 57종 (등장 / 사라짐 / 이동 / 시선 끌기 / 사진 훑기 / 흔들기 /
  자글자글 / 지지직 / 조합)
- 속도 그래프 편집. 일정한 속도가 아니라 쫀득하게 가속·감속하는 곡선을 직접 만듭니다
- 프레임을 벗어날 때의 처리를 고를 수 있습니다 (잘리지 않게 담기 / 원본 크기 유지 /
  여백 없이 채우기)
- 투명 배경(알파 채널) 유지
- **최대 4000px** 까지 만들 수 있습니다
- **자르기.** 미리보기에서 영역을 직접 끌어 자르고, 비율(1:1 / 4:5 / 9:16 ...)을
  잠글 수 있습니다. `빈 여백 자동 제거` 는 투명 여백은 물론 흰 배경 JPG 처럼
  **단색 여백**도 찾아냅니다. 자르면 캔버스도 같이 줄어들어 결과 파일에
  빈 공간이 남지 않습니다
- 미리보기가 곧 결과물입니다. 내보내기 전용 렌더 경로가 없습니다
- 오프라인 사용 가능 (PWA). 주소창의 설치 아이콘을 누르면 앱처럼 씁니다

## 넣은 그대로 시작합니다

이미지를 넣으면 **아무것도 줄이지 않습니다.**

- 캔버스는 지금까지 넣은 이미지 중 **가장 큰 것**에 맞춰집니다. 폭과 높이를 각각
  큰 쪽으로만 넓히므로, 여러 장을 한 번에 떨어뜨리면 그중 제일 큰 크기가 됩니다.
  나중에 작은 그림을 더 넣어도 캔버스는 줄지 않습니다 (상한 4000px)
- 레이어 맞춤은 **원본 크기**, 프레임 처리는 **원본 크기 그대로** 입니다.
  넣은 픽셀이 그대로 앉습니다
- 움직임이 프레임을 벗어나면 그만큼 잘립니다. 잘리는 것이 싫으면 인스펙터 >
  레이어 관계에서 `잘리지 않게` 로 바꾸세요. 그때부터 담기 솔버가 배율을 낮춥니다
- 이미지 다듬기의 `배경 지우기` 는 **꺼진 채로** 시작합니다. 지울 색과 허용치는
  자동으로 추정해 채워 두므로, 체크만 켜면 바로 쓸 수 있습니다

## 레이어 창

- 레이어 목록과 모션 프리셋 사이의 **손잡이를 끌면** 목록 높이가 바뀝니다.
  두 번 누르면 기본 높이로 돌아갑니다. 키보드는 손잡이에 포커스를 준 뒤
  위/아래 화살표(Shift 를 누르면 3배), `Home` / `End` 를 씁니다.
  정한 높이는 브라우저에 남아 다음에 열 때도 그대로입니다
- 패널 머리의 눈 아이콘은 **전체 숨기기 / 전체 보이기**, 자물쇠 아이콘은
  **전체 잠그기 / 전체 잠금 풀기** 입니다. 몇 장이든 한 번의 `Ctrl+Z` 로 되돌아갑니다

## 자르기

EASY 모드에는 `빈 여백 잘라내기` 버튼 하나만 있습니다. 누르면 그림 둘레의
투명하거나 단색인 여백을 찾아 잘라내고 크기를 거기에 맞춥니다.
`원래대로` 로 되돌립니다.

PRO 모드의 인스펙터 > 이미지 다듬기에서는 영역을 직접 정합니다.

| 하고 싶은 것 | 방법 |
| --- | --- |
| 새로 그리기 | 미리보기 빈 곳을 끕니다 |
| 옮기기 | 상자 안쪽을 끕니다 |
| 크기 바꾸기 | 모서리나 변의 핸들을 끕니다 |
| 비율 고정 | `1:1` `4:5` `3:4` `16:9` `9:16` 중 하나를 누릅니다 |
| 1px 단위로 맞추기 | X / Y / 폭 / 높이 숫자 칸을 씁니다 |

`캔버스도 자른 크기에 맞추기` 를 끄면 잘라낸 여백이 프레임의 빈 공간으로
남습니다. 켜 두는 편이 대부분 맞습니다.

## 크기와 용량

- 캔버스 상한은 **4000px** 입니다. 저사양 기기의 텍스처 상한(4096px) 아래로
  잡은 값입니다
- 큰 캔버스는 프레임을 렌더하는 즉시 인코딩해서 버리는 **스트리밍 경로**로
  갑니다. 원시 프레임을 전부 들고 있지 않으므로 4000px 도 만들 수 있습니다
- 만들어지는 파일이 **2GB** 를 넘으면 이유를 알리고 중단합니다. 크기를 한 단계
  줄이거나 속도를 올려(길이가 짧아집니다) 다시 시도하세요

## 브라우저

WebGL2 를 쓰므로 최신 Chrome / Edge / Firefox / Safari 에서 동작합니다.
APNG 와 WebP 는 브라우저마다 지원이 갈리는데, 내보내기 화면의 진단 패널이
이 브라우저에서 직접 재서 알려 줍니다.

## 개발

```bash
npm install
npm run dev
```

| 명령 | 하는 일 |
| --- | --- |
| `npm run dev` | 개발 서버 |
| `npm run build` | 타입 검사 후 빌드 |
| `npm test` | 테스트 |
| `npm run preview` | 빌드 결과 미리보기 |

Windows 에서는 `모션메이커 실행.cmd` 를 더블클릭해도 됩니다.
`바탕화면 바로가기 만들기.cmd` 를 한 번 실행하면 바탕화면에 아이콘이 생깁니다.

## 배포

`main` 브랜치에 밀어 넣으면 GitHub Actions 가 빌드해서 GitHub Pages 로 올립니다
(`.github/workflows/deploy.yml`).

저장소 이름은 워크플로가 빌드할 때 넣어 주므로 설정 파일에 적어 둘 필요가 없습니다.
저장소 이름을 바꿔도 그대로 동작합니다.

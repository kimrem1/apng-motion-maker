# 모션 메이커

이미지 한 장이나 도형만으로 움직이는 이미지(APNG / WebP / GIF)를 만드는 웹 도구입니다.

**모든 처리가 브라우저 안에서 끝납니다.** 이미지가 서버로 올라가지 않습니다.

## 쓰는 법

1. 이미지를 끌어다 놓거나 붙여넣습니다 (Ctrl+V). 이미지 없이 `도형` 으로 시작해도 됩니다
2. 왼쪽에서 움직임을 고릅니다
3. 내보내기를 누릅니다

시작 화면은 **PRO** 입니다. 레이어와 타임라인을 바로 만질 수 있습니다.
프리셋을 고르고 세기/속도 슬라이더만 쓰고 싶으면 위쪽 `EASY` 를 누르세요.

## 특징

- 모션 프리셋 94종 (등장 / 사라짐 / 이동 / 시선 끌기 / 사진 훑기 / 흔들기 /
  자글자글 / 지지직 / 조합 / **글자**)
- **글자 레이어.** 글자를 넣고 글꼴 / 크기 / 자간 / 행간 / 테두리를 정합니다.
  글꼴 파일(.ttf / .otf)을 끌어다 올리면 그 글꼴로 그립니다
- **글자 하나하나가 들어오는 모션 18종.** 왼쪽 / 오른쪽 / 위 / 아래 / 좌우 번갈아 /
  위아래 번갈아 / **사방에서 모이기** / 돌면서 모이기 / 가운데에서 퍼지기 /
  타자기 / 차례로 밝아지기 / 떨어져 튕기기 / 톡톡 튀어나오기 / 멀리서 다가오기 /
  크게 왔다 제자리로 / 제자리에서 돌기 / 카드처럼 뒤집히기 / 물결치듯
- **컷 편집.** 한 타임라인을 여러 컷으로 나누고 레이어를 컷에 넣습니다.
  컷끼리 겹치면 그만큼 디졸브로 넘어갑니다
- **가리기.** 그림은 제자리에 두고 경계선만 지나갑니다. 한쪽에서 걷어내기,
  양문 열림, 원형 아이리스, 시계 방향, 블라인드까지 아홉 가지입니다.
  테두리만 남긴 도형에 시계 모양을 걸면 **선이 그려집니다**
- **입체 뒤집기.** 진짜 원근이 걸린 3D 회전입니다. 카드가 좌우로 돌고 종이가
  앞으로 펼쳐집니다. 가까운 변이 커지고 먼 변이 작아지는 사다리꼴이 나옵니다
- **도형 모션그래픽.** 사각형 / 원 / 삼각형 / 다각형 / 별 / 십자 / 부채꼴 /
  방사살 / 눈금 / 별빛을 넣고 움직입니다. 도형 여러 장이 시간차로 움직이는
  **세트 34종**(양문 열림, 바람개비 살, 격자 카드, 물결 파동, 음악 막대,
  색종이 등)이 한 번의 클릭으로 들어갑니다. 이미지가 없어도 됩니다
- **화면을 가로질러 지나가는 모션.** 왼쪽에서 오른쪽으로 / 오른쪽에서 왼쪽으로 /
  위에서 아래로 / 아래에서 위로. 한쪽 프레임 밖에서 들어와 반대쪽 밖으로 빠집니다
- **모션 기준점.** 회전과 확대가 도는 축을 3x3 에서 고릅니다. 기준점을 옮겨도
  그림이 놓이는 자리는 캔버스 가운데 그대로입니다
- 속도 그래프 편집. 일정한 속도가 아니라 쫀득하게 가속·감속하는 곡선을 직접 만듭니다
- 프레임을 벗어날 때의 처리를 고를 수 있습니다 (잘리지 않게 담기 / 원본 크기 유지 /
  여백 없이 채우기)
- 투명 배경(알파 채널) 유지
- **최대 4000px** 까지 만들 수 있습니다
- **자유 자르기.** EASY 와 PRO 모두에서 미리보기 위를 끌어 남길 영역을 직접
  정합니다. 기본은 비율 제한 없는 **자유**이고, 필요하면 1:1 / 4:5 / 9:16 같은
  비율을 잠급니다. `빈 여백 자동 제거` 는 투명 여백은 물론 흰 배경 JPG 처럼
  **단색 여백**도 찾아냅니다. 자르면 캔버스도 같이 줄어들어 결과 파일에
  빈 공간이 남지 않습니다
- 미리보기가 곧 결과물입니다. 내보내기 전용 렌더 경로가 없습니다
- 오프라인 사용 가능 (PWA). 주소창의 설치 아이콘을 누르면 앱처럼 씁니다

## 넣은 그대로 시작합니다

이미지를 넣으면 **아무것도 줄이지 않습니다.**

- 캔버스는 지금까지 넣은 이미지 중 **가장 큰 것**에 맞춰집니다. 폭과 높이를 각각
  큰 쪽으로만 넓히므로, 여러 장을 한 번에 떨어뜨리면 그중 제일 큰 크기가 됩니다.
  나중에 작은 그림을 더 넣어도 캔버스는 줄지 않습니다 (상한 4000px)
- 레이어 맞춤은 **원본 크기**, 프레임 처리는 **원본 크기 그대로** 입니다.
  넣은 픽셀이 그대로 앉습니다
- 움직임이 프레임을 벗어나면 그만큼 잘립니다. 잘리는 것이 싫으면 인스펙터 >
  레이어 관계에서 `잘리지 않게` 로 바꾸세요. 그때부터 담기 솔버가 배율을 낮춥니다
- 이미지 다듬기의 `배경 지우기` 는 **꺼진 채로** 시작합니다. 지울 색과 허용치는
  자동으로 추정해 채워 두므로, 체크만 켜면 바로 쓸 수 있습니다

## 크기를 바꾸면 그림도 같이 갑니다

`크기`(EASY) 와 `폭` / `높이`(PRO) 는 **결과물 해상도**입니다. 캔버스만 바뀌고
그림이 제자리에 남으면, 크기를 줄였을 때 그림이 커진 것처럼 보이면서 사방이
잘립니다. 그래서 이 컨트롤은 캔버스와 그림을 같은 비율로 함께 옮깁니다.
`늘여 채우기` 가 아니어도 그림이 커지던 문제가 여기서 사라집니다.

자르기처럼 **원본 픽셀 자체가 달라져서** 캔버스가 따라가는 경우는 다릅니다.
그림은 이미 그만큼 작아졌으므로 배율을 또 건드리지 않습니다.

## 도형 모션그래픽

왼쪽 패널 위쪽의 `모션` / `도형` 탭에서 `도형` 을 누릅니다. EASY 와 PRO 둘 다
같은 자리에 있습니다.

**도형 하나 넣기.** 사각형 / 원 / 삼각형 / 다각형 / 별 / 십자 / 부채꼴 /
방사살 / 눈금 / 별빛 열 가지입니다. 넣은 다음 `모션` 탭에서 아무 움직임이나
고르면 그대로 얹힙니다. 도형 레이어는 이미지 레이어와 완전히 같은 트랙 위에 있어서
모션 76종이 전부 걸립니다. 색과 크기, 선 두께, 모서리 둥글기는 인스펙터 >
도형에서 바꿉니다.

뒤의 세 가지가 새로 들어왔습니다.

- **방사살** 은 가운데에서 뻗는 살입니다. 바람개비, 집중선, 방사 눈금이 전부
  이것입니다. 살 서른여섯 개까지 도형 **한 장**으로 만듭니다
- **눈금** 은 일정한 간격으로 늘어선 짧은 막대입니다. 자 눈금과 점선입니다
- **별빛** 은 변이 안으로 파인 뾰족한 별입니다. `별` 은 변이 직선이라
  반짝임에 쓰면 종이별처럼 보입니다

**도형 모션 세트 34종.** 도형 여러 장과 그 시간차까지 한 번에 만듭니다.

| 묶음 | 들어 있는 것 |
| --- | --- |
| 연출 | 양문 열림 / 가로 슬랫 쌓기 / 바람개비 살 / 점에서 선으로 / 조준선 / 카드 흘러가기 / 빛 커튼 / 별빛 터지기 / 격자 카드 / 네모 테두리 그려지기 |
| 퍼지기 | 물결 파동 / 신호등 / 레이더 / 방울 팝 |
| 소리 그래프 | 음악 막대 / 대칭 파형 / 물결 점 / 기다리는 점 |
| 돌기 | 도는 사각 / 궤도 점 / 삼각 스핀 / 회전 링 |
| 강조 | 쫀득 팝 / 반짝임 / 밑줄 긋기 / 테두리 그리기 / 팡 터지기 |
| 화면 전환 | 원형 전환 / 띠 전환 / 셔터 / 대각선 쓸기 |
| 배경 장식 | 떠다니는 원 / 색종이 / 격자 점멸 |

같은 세트를 다시 누르면 **앞에 넣은 것을 갈아끼웁니다.** 색이나 세기를 바꾸려고
슬라이더를 끌 때마다 도형이 쌓이지 않습니다. 다른 세트를 누르면 위에 얹히므로
여러 개를 겹쳐 쓸 수 있습니다.

넣은 뒤에는 그냥 레이어입니다. 한 장만 골라 지우거나, 위치를 옮기거나,
그래프 에디터로 움직임을 다시 손볼 수 있습니다. **한 번이라도 손대면 그때부터는
슬라이더가 그 세트를 다시 만들지 않습니다.** 손본 것을 말없이 되돌리지 않기
위해서입니다. 처음부터 다시 만들고 싶으면 카드를 한 번 더 누르세요.

이미 만들어 둔 타임라인이 있으면 **세트가 그 길이에 맞춥니다.** 5초짜리 모션에
배경 장식을 하나 얹었다고 전체가 1.2초로 줄어들지 않습니다. 이때는 길이가 이미
정해져 있으므로 속도 슬라이더가 꺼집니다.

**이미지가 없어도 됩니다.** 시작 화면의 `이미지 없이 도형으로 시작` 으로 바로
만들고 그대로 내보낼 수 있습니다.

도형은 픽셀이 아니라 수식으로 그립니다. 4000px 로 키워도 가장자리가 뭉개지지
않고, 도형을 늘려도 원본 이미지가 늘지 않습니다.

## 글자

왼쪽 패널의 `글자` 탭에서 `글자 넣기` 를 누릅니다. 내용과 글꼴은 인스펙터 > 글자에서
바꿉니다. 도형과 마찬가지로 **이미지가 없어도 됩니다.**

**글자는 하나하나 따로 움직입니다.** `사방에서 모이기` 를 고르면 글자마다 다른
방향에서 날아와 한 줄로 모입니다. 방향과 순서와 시간차는 따로 정합니다.

| 정하는 것 | 뜻 |
| --- | --- |
| 들어오는 모양 | 어느 쪽에서 오는가 (18가지) |
| 속도 곡선 | 글자 하나가 제자리까지 가는 속도 (7가지) |
| 순서 | 앞에서부터 / 뒤에서부터 / 가운데에서 / 양끝에서 / 무작위 |
| 글자 시간차 | 0 이면 전부 동시에, 1 이면 한 글자씩 차례로 |
| 출발 거리 | 글자 크기의 몇 배만큼 떨어진 곳에서 오는가 |
| 도착 흔들림 | 0 이면 기계처럼 균일. 조금 흔들어야 사람이 만든 것처럼 보인다 |
| 시작 / 걸리는 시간 | 언제 시작해 몇 초에 걸쳐 들어오는가. 짧게 할수록 빨라진다 |

**속도 곡선은 글자마다 따로 걸립니다.** 시간차는 출발 시각만 밀고, 곡선은 글자
하나하나가 각자 갖습니다. 전체 진행률에 한 번만 걸면 첫 글자는 곡선의 가파른
앞부분을, 마지막 글자는 평평한 꼬리를 받아서 글자 하나로 보면 등속이 됩니다.
그러면 아무리 센 곡선을 걸어도 밋밋합니다.

`살짝 지나쳤다 돌아오기`(기본값)와 `탱탱하게 흔들리기`, `통통 튀기` 는 일부러 목표를
지나쳤다가 제자리를 잡습니다. 그 되돌아오는 구간이 쫀득함의 정체입니다.

진행률은 별도의 트랙(`글자 등장`)입니다. 가리기와 똑같이 스톱워치를 켜서 시간에 따라
밀 수 있고, 그래프 에디터로 가속·감속을 넣을 수도 있습니다. **진행률 0 이면 전부
출발점, 1 이면 전부 제자리입니다.** 시간차를 아무리 크게 줘도 그렇습니다.

글꼴은 앱에 넣어 두지 않습니다. 결과물이 이미지라 보는 사람 PC 에 그 글꼴이 없어도
되고, 한글 글꼴 하나가 몇 MB 라 첫 로딩이 그만큼 느려지기 때문입니다. 대신 `글꼴 파일
올리기` 로 원하는 글꼴을 직접 올립니다. **올린 글꼴은 이번 세션에만 남습니다.**

### 같은 등장을 이미지와 도형에도

인스펙터 > `오브제 등장` 입니다. 글자 등장과 **같은 규칙, 같은 곡선**이 이미지와
도형에도 그대로 걸립니다. 오브제를 "글자가 한 개짜리 글 상자" 로 계산하기 때문에
`왼쪽에서 밀려들어오기` 같은 프리셋을 사진에 걸어도 글자와 똑같은 리듬으로 들어옵니다.

`출발 거리` 는 **자기 크기의 배수**입니다. 1.4 면 제 폭의 1.4 배 밖에서 출발하므로
큰 사진도 작은 도형도 각자 화면 밖에서 들어옵니다. 캔버스 크기로 재면 작은 도형이
저 멀리서 순간이동해 오는 것처럼 보입니다.

글자가 여럿일 때만 뜻이 있는 것(순서 / 글자 시간차 / 도착 흔들림)은 오브제에서
숨깁니다. `좌우에서 번갈아` 처럼 홀짝으로 방향이 갈리는 프리셋도 목록에서 빠집니다.
오브제는 언제나 0 번이라 이름과 다르게 한쪽으로만 들어오기 때문입니다.

## 컷 편집

왼쪽 패널의 `컷` 탭입니다. 컷은 별도의 파일이 아니라 **한 타임라인을 나눈 구간**입니다.
그래서 컷을 써도 그래프 에디터와 모션 프리셋이 지금까지와 똑같이 동작합니다.

1. `컷 추가` 로 컷을 만듭니다. 전체 길이가 그만큼 늘어납니다
2. 레이어를 고르고 `이 컷에 넣기` 를 누릅니다
3. `앞 컷과 겹침` 을 올리면 그만큼 앞 컷이 사라지며 뒤 컷이 떠오릅니다. 0 이면 딱 잘립니다

컷에 넣지 않은 레이어는 **모든 컷에서 계속 보입니다.** 로고나 배경처럼 끝까지 남아야
하는 것을 그대로 두면 됩니다.

## 가리기

그림을 옮기거나 흐리게 하는 대신 **경계선이 지나가게** 합니다. 실제 방송 자막과
컷인이 거의 전부 이 방식입니다.

PRO 의 인스펙터 > 가리기에서 모양을 고릅니다.

| 모양 | 어떻게 지나가는가 |
| --- | --- |
| 왼쪽 / 오른쪽 / 위 / 아래에서 | 한쪽 끝에서 반대쪽으로 쓸고 지나갑니다 |
| 가운데에서 좌우로 / 위아래로 | 양문이 열리듯 갈라집니다 |
| 가운데에서 원으로 | 동그란 구멍이 자랍니다 |
| 시계 방향으로 | 열두 시부터 한 바퀴 돕니다 |
| 블라인드 | 가로 칸마다 따로 열립니다 |

`경계 흐림` 이 0 이면 칼로 자른 듯 끊기고, 올리면 스며들듯 드러납니다.
진행률 0 과 1 에서는 흐림과 무관하게 **완전히 가려지고 완전히 보입니다.**

`반대로 뒤집기` 는 경계선이 **어느 쪽에서 오는지**를 바꿉니다. 되감기가 아닙니다.
거꾸로 재생하고 싶으면 진행률 트랙을 1 에서 0 으로 찍으면 됩니다.

진행률은 별도의 트랙입니다. 스톱워치를 켜면 타임라인에서 시간에 따라 밀 수 있고,
그래프 에디터로 가속·감속을 넣을 수도 있습니다.

**테두리만 남긴 도형에 `시계 방향` 을 걸면 선이 그려집니다.** 도형 세트의
`네모 테두리 그려지기` 와 `바람개비 살` 이 이 방식입니다.

경계선은 레이어를 따라 돕니다. 카드를 45도 기울이면 경계선도 같이 기울어집니다.

## 입체 뒤집기

`세로축 회전` 은 카드가 좌우로 도는 것이고, `가로축 회전` 은 종이가 앞뒤로 눕는
것입니다. 인스펙터 > 레이어에 있고, 다른 값과 똑같이 스톱워치를 켜서 애니메이션할
수 있습니다.

**진짜 원근이 걸립니다.** 가로 폭을 눌러 흉내내는 방식이 아니라, 가까운 변이
커지고 먼 변이 작아지는 사다리꼴이 나옵니다.

`원근 거리` 는 레이어 긴 변의 몇 배만큼 떨어져서 보는가입니다. 작을수록 원근이
세고, 0 이면 원근 없이 각도만큼만 눌립니다. px 가 아니라 배수인 이유는 캔버스
크기를 바꿔도 같은 그림이 나와야 하기 때문입니다.

프리셋으로는 `카드 뒤집으며 등장` / `종이 펼치며 등장` / `카드 뒤집으며 사라짐` /
`카드 한 바퀴` / `입체로 기울이기` 다섯 가지가 있습니다.

## 모션 기준점

회전과 확대가 도는 축입니다. EASY 는 `빠른 설정`, PRO 는 인스펙터 > 레이어에서
3x3 으로 고릅니다.

기준점을 옮겨도 **그림이 놓이는 자리는 바뀌지 않습니다.** 캔버스(자른 상태라면
자른 크기)의 한가운데를 기준으로, 도는 축만 옮겨집니다. 왼쪽 위를 고르면
왼쪽 위 모서리가 박힌 채로 회전하고, 확대도 그쪽에서 자랍니다.

## 레이어 창

- 레이어 목록과 모션 프리셋 사이의 **손잡이를 끌면** 목록 높이가 바뀝니다.
  두 번 누르면 기본 높이로 돌아갑니다. 키보드는 손잡이에 포커스를 준 뒤
  위/아래 화살표(Shift 를 누르면 3배), `Home` / `End` 를 씁니다.
  정한 높이는 브라우저에 남아 다음에 열 때도 그대로입니다
- 패널 머리의 눈 아이콘은 **전체 숨기기 / 전체 보이기**, 자물쇠 아이콘은
  **전체 잠그기 / 전체 잠금 풀기** 입니다. 몇 장이든 한 번의 `Ctrl+Z` 로 되돌아갑니다

## 자르기

EASY 모드에는 두 가지가 있습니다.

- `빈 여백 잘라내기` 는 그림 둘레의 투명하거나 단색인 여백을 찾아 한 번에
  잘라냅니다. `원래대로` 로 되돌립니다
- `직접 자르기` 는 창을 열어 **남길 영역을 직접 끕니다.** 기본은 비율 자유이고,
  1:1 같은 고정 비율도 고를 수 있습니다. `원본으로 되돌리기` 가 창 안에 있습니다

PRO 모드는 인스펙터 > 이미지 다듬기에서 같은 일을 합니다.

| 하고 싶은 것 | 방법 |
| --- | --- |
| 자유롭게 자르기 | 비율에서 `자유` 를 고릅니다 (기본값) |
| 새로 그리기 | 미리보기 빈 곳을 끕니다 |
| 옮기기 | 상자 안쪽을 끕니다 |
| 크기 바꾸기 | 모서리나 변의 핸들을 끕니다 |
| 비율 고정 | `1:1` `4:5` `3:4` `16:9` `9:16` 중 하나를 누릅니다 |
| 1px 단위로 맞추기 | X / Y / 폭 / 높이 숫자 칸을 씁니다 |

`캔버스도 자른 크기에 맞추기` 를 끄면 잘라낸 여백이 프레임의 빈 공간으로
남습니다. 켜 두는 편이 대부분 맞습니다.

## 크기와 용량

- 캔버스 상한은 **4000px** 입니다. 저사양 기기의 텍스처 상한(4096px) 아래로
  잡은 값입니다
- 큰 캔버스는 프레임을 렌더하는 즉시 인코딩해서 버리는 **스트리밍 경로**로
  갑니다. 원시 프레임을 전부 들고 있지 않으므로 4000px 도 만들 수 있습니다
- 만들어지는 파일이 **2GB** 를 넘으면 이유를 알리고 중단합니다. 크기를 한 단계
  줄이거나 속도를 올려(길이가 짧아집니다) 다시 시도하세요

## 브라우저

WebGL2 를 쓰므로 최신 Chrome / Edge / Firefox / Safari 에서 동작합니다.
APNG 와 WebP 는 브라우저마다 지원이 갈리는데, 내보내기 화면의 진단 패널이
이 브라우저에서 직접 재서 알려 줍니다.

## 개발

```bash
npm install
npm run dev
```

| 명령 | 하는 일 |
| --- | --- |
| `npm run dev` | 개발 서버 |
| `npm run build` | 타입 검사 후 빌드 |
| `npm test` | 테스트 |
| `npm run preview` | 빌드 결과 미리보기 |

Windows 에서는 `모션메이커 실행.cmd` 를 더블클릭해도 됩니다.
`바탕화면 바로가기 만들기.cmd` 를 한 번 실행하면 바탕화면에 아이콘이 생깁니다.

## 배포

`main` 브랜치에 밀어 넣으면 GitHub Actions 가 빌드해서 GitHub Pages 로 올립니다
(`.github/workflows/deploy.yml`).

저장소 이름은 워크플로가 빌드할 때 넣어 주므로 설정 파일에 적어 둘 필요가 없습니다.
저장소 이름을 바꿔도 그대로 동작합니다.

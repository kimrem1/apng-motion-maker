# 모션 메이커

이미지 한 장이나 도형만으로 움직이는 이미지(APNG / WebP / GIF)를 만드는 웹 도구입니다.

**모든 처리가 브라우저 안에서 끝납니다.** 이미지가 서버로 올라가지 않습니다.

## 쓰는 법

1. 이미지를 끌어다 놓거나 붙여넣습니다 (Ctrl+V). 이미지 없이 `도형` 으로 시작해도 됩니다
2. 왼쪽에서 움직임을 고릅니다
3. 내보내기를 누릅니다

**켠 카드를 다시 누르면 꺼집니다.** 모션 프리셋, 도형 세트, 글자 등장 셋 다
같은 규칙입니다. 얹어 보고 물리는 것이 가장 잦은 조작인데 그 길이 `Ctrl+Z` 뿐이면
그 사이에 한 다른 작업까지 함께 되감깁니다. 뺄 때도 **사용자가 직접 만든 트랙과
효과는 그대로 남습니다.** 프리셋이 심은 것만 걷어냅니다.

시작 화면은 **PRO** 입니다. 레이어와 타임라인을 바로 만질 수 있습니다.
프리셋을 고르고 세기/속도 슬라이더만 쓰고 싶으면 위쪽 `EASY` 를 누르세요.

## 특징

- 모션 프리셋 105종 (등장 / 사라짐 / 이동 / 시선 끌기 / 사진 훑기 / 흔들기 /
  자글자글 / 지지직 / 조합 / **글자**)
- **타격감 진동 6종.** 강펀치 / 내려찍기 / 반동 / 쿵쿵 울림 / 연타 /
  부르르 진동. 맞은 것처럼 한 프레임 만에 튕겼다가 길게 잦아듭니다
- **캔버스에서 끌어 옮기기.** 미리보기 위에서 그림을 직접 끌어 자리를 잡습니다.
  폴더를 골라 두면 폴더째, 여러 장을 골라 두면 간격을 지킨 채 함께 갑니다
- **격자와 딱 붙이기.** 미리보기 아래 `격자` (Ctrl+') 를 켜면 격자가 보이고,
  끌어 옮길 때 칸에 정확히 맞춰 앉습니다. 칸은 8 / 16 / 32 / 64px 입니다
- **글자 레이어.** 글자를 넣고 글꼴 / 크기 / 자간 / 행간 / 테두리를 정합니다.
  글꼴 파일(.ttf / .otf)을 끌어다 올리면 그 글꼴로 그립니다
- **글자 하나하나가 들어오는 모션 19종.** 왼쪽 / 오른쪽 / 위 / 아래 / 좌우 번갈아 /
  위아래 번갈아 / **사방에서 모이기** / 돌면서 모이기 / 가운데에서 퍼지기 /
  타자기 / 차례로 밝아지기 / 떨어져 튕기기 / 톡톡 튀어나오기 / 멀리서 다가오기 /
  크게 왔다 제자리로 / 제자리에서 돌기 / 카드처럼 뒤집히기 / 물결치듯 /
  **글자 굴리며 확정**
- **타임라인이 전체를 보여 줍니다.** 고른 레이어 하나가 아니라 **문서의 모든
  레이어**가 한 줄씩 놓입니다. 막대가 그 레이어가 보이는 구간이고, 끌어 옮기거나
  양끝을 잡아 늘이면 **있다 없다**가 정해집니다. 레이어 목록의 손잡이를 타임라인
  위로 끌고 가면 그 프레임부터 보이게 놓입니다
- **그림 바꿔 끼우기(눈 깜빡임).** 그림 여러 장을 고르고 `차례로 나누기` 를 누르면
  겹침 없이 순서대로 나뉩니다. 페이드가 0 이라 **딱딱 바뀝니다**
- **컷 편집.** 한 타임라인을 여러 컷으로 나누고 레이어를 컷에 넣습니다.
  컷끼리 겹치면 그만큼 디졸브로 넘어갑니다
- **가리기.** 그림은 제자리에 두고 경계선만 지나갑니다. 한쪽에서 걷어내기,
  양문 열림, 원형 아이리스, 시계 방향, 블라인드, **잉크처럼 번지며**,
  **부채처럼 펼쳐지며** 까지 열한 가지입니다.
  테두리만 남긴 도형에 시계 모양을 걸면 **선이 그려집니다**
- **입체 뒤집기와 경첩.** 진짜 원근이 걸린 3D 회전입니다. 카드가 좌우로 돌고
  종이가 앞으로 펼쳐집니다. **경첩**은 한쪽 변이 한 픽셀도 움직이지 않는 채로
  문처럼 젖혀집니다. 봉투 뚜껑과 여닫이문이 이 모양입니다
- **도형 모션그래픽.** 사각형 / 원 / 삼각형 / 다각형 / 별 / 십자 / 부채꼴 /
  방사살 / 눈금 / 별빛을 넣고 움직입니다. 도형 여러 장이 시간차로 움직이는
  **세트 43종**(양문 열림, 바람개비 살, 격자 패널 열림, 카드 부채꼴, 병풍 열림,
  사선 테이프, 흩날리는 꽃잎, 흐르는 띠, 물결 파동, 음악 막대 등)이 한 번의
  클릭으로 들어갑니다. 이미지가 없어도 되고, 세트는 폴더에 담겨 나옵니다
- **레이어 폴더.** 여러 장을 묶고 **폴더에도 모션을 겁니다.** 안쪽 모션과 폴더
  모션이 겹쳐서 함께 보입니다. 도형 세트도 폴더에 담겨 나옵니다
- **아래 모양으로 자르기.** 사진을 글자 모양으로 자르거나 무늬를 도형 안에만
  채웁니다. 기준은 아래 레이어의 알파라 반투명한 가장자리가 그대로 살아납니다.
  **폴더도 자르고 폴더로도 자릅니다.** 레이어 목록의 가위 단추나 `C` 로 켭니다
- **효과 23종.** 그라데이션 / **광택 훑기** / **번지는 빛** / **잔상 겹치기** /
  부드러운 흐림 / 방향성 블러 / 렌즈 색수차 / 노이즈 / 종이 질감 / 색 보정 /
  비네트 / 하프톤 / 포스터화 / 픽셀화 / 스캔라인 / RGB 분리 / 색 번짐 /
  조각 밀림 / 블록 / 밴드 / 픽셀 정렬 / 자글자글 / 렌즈 왜곡
- **화면을 가로질러 지나가는 모션.** 왼쪽에서 오른쪽으로 / 오른쪽에서 왼쪽으로 /
  위에서 아래로 / 아래에서 위로. 한쪽 프레임 밖에서 들어와 반대쪽 밖으로 빠집니다
- **모션 기준점.** 회전과 확대가 도는 축을 3x3 에서 고릅니다. 기준점을 옮겨도
  그림이 놓이는 자리는 캔버스 가운데 그대로입니다
- **템플릿으로 쓰기.** 맞춰 둔 움직임은 그대로 두고 **그림만 갈아끼웁니다.**
  레이어를 새로 만들지 않으므로 트랙 · 효과 · 가리기 · 구간이 한 개도 사라지지
  않고, 크기가 다른 그림을 끼워도 화면에서 차지하던 크기를 지킵니다
- **모션 옮기기.** 한 오브제에 맞춰 둔 움직임과 효과를 다른 오브제로 그대로
  보냅니다. 움직임 / 효과 / 가리기를 갈래별로 고를 수 있고, 사본만 보내거나
  원본에서 빼고 넘길 수 있습니다. EASY 에서는 한 번에 나머지 전부로 갑니다
- **오브제마다 다른 속도.** `이 오브제만 빠르게` 는 **전체 길이와 초당 프레임을
  건드리지 않고** 그 오브제만 여러 바퀴 돌립니다. 배경은 천천히, 앞의 아이콘만
  빠르게가 이렇게 나옵니다. 반복 이음새가 끊기지 않도록 정수 배로만 올립니다
- **내보낼 때 돌리고 뒤집기.** 결과 파일 자체를 90도 단위로 돌리고 좌우·상하로
  뒤집습니다. 픽셀 자리만 바뀌므로 화질이 한 픽셀도 상하지 않습니다
- **용량 다이어트.** 눈에 안 보이는 미세한 색 흔들림을 얼려서 **해상도도 색상도
  그대로 둔 채** 파일만 줄입니다. 그레인 제거와 함께 쓰면 더 잘 듭니다.
  목표 용량 맞추기가 이 축을 가장 먼저 씁니다
- 속도 그래프 편집. 일정한 속도가 아니라 쫀득하게 가속·감속하는 곡선을 직접 만듭니다
- 프레임을 벗어날 때의 처리를 고를 수 있습니다 (잘리지 않게 담기 / 원본 크기 유지 /
  여백 없이 채우기)
- 투명 배경(알파 채널) 유지
- **최대 4000px** 까지 만들 수 있습니다
- **자유 자르기.** EASY 와 PRO 모두에서 미리보기 위를 끌어 남길 영역을 직접
  정합니다. 기본은 비율 제한 없는 **자유**이고, 필요하면 1:1 / 4:5 / 9:16 같은
  비율을 잠급니다. `빈 여백 자동 제거` 는 투명 여백은 물론 흰 배경 JPG 처럼
  **단색 여백**도 찾아냅니다. 자르면 캔버스도 같이 줄어들어 결과 파일에
  빈 공간이 남지 않습니다
- 미리보기가 곧 결과물입니다. 내보내기 전용 렌더 경로가 없습니다
- 오프라인 사용 가능 (PWA). 주소창의 설치 아이콘을 누르면 앱처럼 씁니다

## 넣은 그대로 시작합니다

이미지를 넣으면 **아무것도 줄이지 않습니다.**

- 캔버스는 지금까지 넣은 이미지 중 **가장 큰 것**에 맞춰집니다. 폭과 높이를 각각
  큰 쪽으로만 넓히므로, 여러 장을 한 번에 떨어뜨리면 그중 제일 큰 크기가 됩니다.
  나중에 작은 그림을 더 넣어도 캔버스는 줄지 않습니다 (상한 4000px)
- 레이어 맞춤은 **원본 크기**, 프레임 처리는 **원본 크기 그대로** 입니다.
  넣은 픽셀이 그대로 앉습니다
- 움직임이 프레임을 벗어나면 그만큼 잘립니다. 잘리는 것이 싫으면 인스펙터 >
  레이어 관계에서 `잘리지 않게` 로 바꾸세요. 그때부터 담기 솔버가 배율을 낮춥니다
- 이미지 다듬기의 `배경 지우기` 는 **꺼진 채로** 시작합니다. 지울 색과 허용치는
  자동으로 추정해 채워 두므로, 체크만 켜면 바로 쓸 수 있습니다

## 크기를 바꾸면 그림도 같이 갑니다

`크기`(EASY) 와 `폭` / `높이`(PRO) 는 **결과물 해상도**입니다. 캔버스만 바뀌고
그림이 제자리에 남으면, 크기를 줄였을 때 그림이 커진 것처럼 보이면서 사방이
잘립니다. 그래서 이 컨트롤은 캔버스와 그림을 같은 비율로 함께 옮깁니다.
`늘여 채우기` 가 아니어도 그림이 커지던 문제가 여기서 사라집니다.

자르기처럼 **원본 픽셀 자체가 달라져서** 캔버스가 따라가는 경우는 다릅니다.
그림은 이미 그만큼 작아졌으므로 배율을 또 건드리지 않습니다.

## 도형 모션그래픽

왼쪽 패널 위쪽의 `모션` / `도형` 탭에서 `도형` 을 누릅니다. EASY 와 PRO 둘 다
같은 자리에 있습니다.

**도형 하나 넣기.** 사각형 / 원 / 삼각형 / 다각형 / 별 / 십자 / 부채꼴 /
방사살 / 눈금 / 별빛 열 가지입니다. 넣은 다음 `모션` 탭에서 아무 움직임이나
고르면 그대로 얹힙니다. 도형 레이어는 이미지 레이어와 완전히 같은 트랙 위에 있어서
모션 76종이 전부 걸립니다. 색과 크기, 선 두께, 모서리 둥글기는 인스펙터 >
도형에서 바꿉니다.

뒤의 세 가지가 새로 들어왔습니다.

- **방사살** 은 가운데에서 뻗는 살입니다. 바람개비, 집중선, 방사 눈금이 전부
  이것입니다. 살 서른여섯 개까지 도형 **한 장**으로 만듭니다
- **눈금** 은 일정한 간격으로 늘어선 짧은 막대입니다. 자 눈금과 점선입니다
- **별빛** 은 변이 안으로 파인 뾰족한 별입니다. `별` 은 변이 직선이라
  반짝임에 쓰면 종이별처럼 보입니다

**도형 모션 세트 43종.** 도형 여러 장과 그 시간차까지 한 번에 만듭니다.

| 묶음 | 들어 있는 것 |
| --- | --- |
| 연출 | 양문 열림 / 가로 슬랫 쌓기 / 바람개비 살 / 점에서 선으로 / 조준선 / 카드 흘러가기 / 빛 커튼 / 별빛 터지기 / 격자 카드 / 네모 테두리 그려지기 / 격자 패널 열림 / 모여서 격자로 / 문 열리며 빛줄기 / 귀퉁이 괄호 / **카드 부채꼴** / **병풍 열림** |
| 퍼지기 | 물결 파동 / 신호등 / 레이더 / 방울 팝 |
| 소리 그래프 | 음악 막대 / 대칭 파형 / 물결 점 / 기다리는 점 / **흐르는 띠** |
| 돌기 | 도는 사각 / 궤도 점 / 삼각 스핀 / 회전 링 |
| 강조 | 쫀득 팝 / 반짝임 / 밑줄 긋기 / 테두리 그리기 / 팡 터지기 |
| 화면 전환 | 원형 전환 / 띠 전환 / 셔터 / 대각선 쓸기 / **사선 테이프** |
| 배경 장식 | 떠다니는 원 / 색종이 / 격자 점멸 / **흩날리는 꽃잎** |

**카드 부채꼴** 은 카드가 아래에서 날아와 부채꼴로 펼쳐졌다 다시 모입니다.
회전축이 카드 **아래 끝**이라 한복판을 돌릴 때 나오는 바람개비가 되지 않습니다.

**병풍 열림** 은 세로 판이 경첩을 축으로 차례로 펴집니다. 경첩이 판마다 **번갈아**
붙는 것이 여닫이문과의 차이입니다. 한쪽으로만 접으면 두루마리가 말립니다.

**사선 테이프** 와 **흐르는 띠** 의 빗금은 `눈금` 도형 **한 장**입니다. 한 칸의
폭이 정확히 `도형 폭 / 칸 수` 라, 흐르는 띠는 딱 그만큼만 밀어 **이음새가
없습니다.** 40프레임을 돌아 첫 프레임과 한 픽셀도 다르지 않습니다.

같은 세트를 다시 누르면 **앞에 넣은 것을 갈아끼웁니다.** 색이나 세기를 바꾸려고
슬라이더를 끌 때마다 도형이 쌓이지 않습니다. 다른 세트를 누르면 위에 얹히므로
여러 개를 겹쳐 쓸 수 있습니다.

넣은 뒤에는 그냥 레이어입니다. 한 장만 골라 지우거나, 위치를 옮기거나,
그래프 에디터로 움직임을 다시 손볼 수 있습니다. **한 번이라도 손대면 그때부터는
슬라이더가 그 세트를 다시 만들지 않습니다.** 손본 것을 말없이 되돌리지 않기
위해서입니다. 처음부터 다시 만들고 싶으면 카드를 한 번 더 누르세요.

이미 만들어 둔 타임라인이 있으면 **세트가 그 길이에 맞춥니다.** 5초짜리 모션에
배경 장식을 하나 얹었다고 전체가 1.2초로 줄어들지 않습니다. 속도 슬라이더는 그
길이 안에서 세트가 도는 빠르기를 정합니다.

**이미지가 없어도 됩니다.** 시작 화면의 `이미지 없이 도형으로 시작` 으로 바로
만들고 그대로 내보낼 수 있습니다.

도형은 픽셀이 아니라 수식으로 그립니다. 4000px 로 키워도 가장자리가 뭉개지지
않고, 도형을 늘려도 원본 이미지가 늘지 않습니다.

## 글자

왼쪽 패널의 `글자` 탭에서 `글자 넣기` 를 누릅니다. 내용과 글꼴은 인스펙터 > 글자에서
바꿉니다. 도형과 마찬가지로 **이미지가 없어도 됩니다.**

**글자는 하나하나 따로 움직입니다.** `사방에서 모이기` 를 고르면 글자마다 다른
방향에서 날아와 한 줄로 모입니다. 방향과 순서와 시간차는 따로 정합니다.

| 정하는 것 | 뜻 |
| --- | --- |
| 들어오는 모양 | 어느 쪽에서 오는가 (19가지) |
| 속도 곡선 | 글자 하나가 제자리까지 가는 속도 (7가지) |
| 순서 | 앞에서부터 / 뒤에서부터 / 가운데에서 / 양끝에서 / 무작위 |
| 글자 시간차 | 0 이면 전부 동시에, 1 이면 한 글자씩 차례로 |
| 출발 거리 | 글자 크기의 몇 배만큼 떨어진 곳에서 오는가 |
| 도착 흔들림 | 0 이면 기계처럼 균일. 조금 흔들어야 사람이 만든 것처럼 보인다 |
| 시작 / 걸리는 시간 | 언제 시작해 몇 초에 걸쳐 들어오는가. 짧게 할수록 빨라진다 |

**속도 곡선은 글자마다 따로 걸립니다.** 시간차는 출발 시각만 밀고, 곡선은 글자
하나하나가 각자 갖습니다. 전체 진행률에 한 번만 걸면 첫 글자는 곡선의 가파른
앞부분을, 마지막 글자는 평평한 꼬리를 받아서 글자 하나로 보면 등속이 됩니다.
그러면 아무리 센 곡선을 걸어도 밋밋합니다.

`살짝 지나쳤다 돌아오기`(기본값)와 `탱탱하게 흔들리기`, `통통 튀기` 는 일부러 목표를
지나쳤다가 제자리를 잡습니다. 그 되돌아오는 구간이 쫀득함의 정체입니다.

**이름이 다른 모양은 화면에서도 다릅니다.** 한동안 세 쌍이 조용히 겹쳐 있었습니다.
`위에서` 와 `위에서 떨어지며` 가 방향만 같고 나머지가 똑같았고, `물결치듯` 이
`위아래 번갈아` 와 같은 코드였고, `멀리서 다가오며` 와 `커다랗게 작아지며` 는
출발 배율을 안 정하면 둘 다 아무것도 움직이지 않는 페이드가 됐습니다. 지금은
떨어지는 쪽이 **닿는 순간 한 번 눌렸다 펴지고**, 물결은 여섯 글자마다 굽이 하나로
**진폭이 순번마다 바뀌며**, 다가오기와 작아지기는 배율을 안 정해도 각각 작은 점과
큰 그림에서 출발합니다. 열여섯 종 전부가 서로 다른 그림을 낸다는 것을 테스트가
쌍마다 확인합니다.

진행률은 별도의 트랙(`글자 등장`)입니다. 가리기와 똑같이 스톱워치를 켜서 시간에 따라
밀 수 있고, 그래프 에디터로 가속·감속을 넣을 수도 있습니다. **진행률 0 이면 전부
출발점, 1 이면 전부 제자리입니다.** 시간차를 아무리 크게 줘도 그렇습니다.

### 글자 굴리며 확정

다른 열여덟 종이 **자리와 크기와 투명도**를 움직이는 데 비해, 이 하나는 그 셋을
전혀 건드리지 않고 **그리는 글자**만 바꿉니다. 처음부터 줄 전체가 아무 글자로
채워져 있다가 왼쪽부터 하나씩 제 글자로 멎습니다.

굴릴 글자를 따로 정해 두지 않습니다. **같은 글 상자 안의 다른 글자를 빌려 씁니다.**
그래서 한글은 한글로, 일본어는 일본어로, 라틴은 라틴으로 굴러갑니다. 후보 목록을
박아 두면 어느 언어에서는 맞고 어느 언어에서는 남의 글자가 섞입니다. 굴리는 동안
**자기 글자는 절대 빌리지 않습니다.** 한 컷이라도 정답이 보이면 "굴렸다" 가 아니라
"깜빡였다" 로 읽힙니다.

글자가 두 개 이상이어야 합니다. 오브제(이미지 / 도형)는 빌릴 칸이 자기 하나뿐이라
목록에서 빠집니다.

글꼴은 앱에 넣어 두지 않습니다. 결과물이 이미지라 보는 사람 PC 에 그 글꼴이 없어도
되고, 한글 글꼴 하나가 몇 MB 라 첫 로딩이 그만큼 느려지기 때문입니다. 대신 `글꼴 파일
올리기` 로 원하는 글꼴을 직접 올립니다. **올린 글꼴은 이번 세션에만 남습니다.**

목록에 있는 글꼴 일곱 가지(고딕, 프리텐다드, 노토 산스, 명조, 둥근 고딕, 고정폭,
굵은 제목)는 **PC 에 설치돼 있을 때만** 그 글꼴로 그려집니다. 없으면 맑은 고딕 같은
대체 글꼴로 떨어집니다. 반드시 그 글꼴이어야 한다면 글꼴 파일을 직접 올리세요.

### 같은 등장을 이미지와 도형에도

인스펙터 > `오브제 등장` 입니다. 글자 등장과 **같은 규칙, 같은 곡선**이 이미지와
도형에도 그대로 걸립니다. 오브제를 "글자가 한 개짜리 글 상자" 로 계산하기 때문에
`왼쪽에서 밀려들어오기` 같은 프리셋을 사진에 걸어도 글자와 똑같은 리듬으로 들어옵니다.

`출발 거리` 는 **자기 크기의 배수**입니다. 1.4 면 제 폭의 1.4 배 밖에서 출발하므로
큰 사진도 작은 도형도 각자 화면 밖에서 들어옵니다. 캔버스 크기로 재면 작은 도형이
저 멀리서 순간이동해 오는 것처럼 보입니다.

글자가 여럿일 때만 뜻이 있는 것(순서 / 글자 시간차 / 도착 흔들림)은 오브제에서
숨깁니다. `좌우에서 번갈아` 처럼 홀짝으로 방향이 갈리는 프리셋도 목록에서 빠집니다.
오브제는 언제나 0 번이라 이름과 다르게 한쪽으로만 들어오기 때문입니다.

## 템플릿으로 쓰기

한 번 맞춰 둔 움직임에 **그림만 갈아끼워** 스티커 세트를 뽑는 흐름입니다.

레이어 목록에서 그림 레이어 줄의 첫 단추(`그림만 갈아끼우기`)를 누르고 새 파일을
고릅니다. EASY 에서는 오른쪽의 `그림만 바꾸기` 입니다.

**그대로 남는 것**: 움직임 · 흔들림 · 효과 · 가리기 · 등장 · 기준점 · 모션 배수 ·
보이는 구간 · 폴더 소속 · 혼합 · 자리 · 화면에서 차지하던 크기.
**바뀌는 것**: 그림 하나뿐입니다.

레이어를 지우고 새로 넣는 것과 다릅니다. 새로 넣으면 레이어 id 가 바뀌면서 위의
목록이 통째로 사라지고, 프리셋을 다시 눌러 되살릴 수 있는 것은 프리셋이 심은 것뿐입니다.
그래프 에디터로 다듬은 곡선과 손으로 쌓은 효과는 돌아오지 않습니다.

**크기도 지킵니다.** 맞춤이 `원본 크기` 면 그림 크기가 곧 화면 크기라, 500px 로 만든
템플릿에 2000px 를 끼우면 네 배로 튀어나옵니다. 긴 변이 같아지도록 배율을 자동으로
맞춥니다. 가로 사진을 세로 사진으로 바꿔도 같은 상자 안에 들어옵니다.
`꽉 채우기` 나 `전체 보이기` 는 맞춤이 이미 크기를 정하므로 건드리지 않습니다.

**캔버스는 그대로입니다.** 결과물 해상도가 고정된 것이 템플릿의 전제이기 때문입니다.
새 그림이 더 커도 캔버스가 따라 늘어나지 않습니다.

레이어 이름은 파일 이름을 따라갑니다. 단, 이름을 직접 바꿔 둔 레이어(`주인공` 처럼)는
그 이름을 지킵니다.

오브제가 여럿인 화면에서 **다른 오브제의 움직임을 그대로 가져오고 싶으면**
[효과와 모션 옮기기](#효과와-모션-옮기기) 를 쓰세요. 이쪽은 그림을 바꾸고,
저쪽은 움직임을 옮깁니다.

## 모션 속도

속도를 정하는 손잡이가 두 개입니다. 두 개인 데는 이유가 있습니다.

| 손잡이 | 무엇을 바꾸는가 | 어디에 있는가 |
| --- | --- | --- |
| 속도 슬라이더 | **전체 길이와 초당 프레임** | EASY 왼쪽 / 모션 갤러리 아래 |
| 이 오브제만 빠르게 | **그 오브제의 움직임만** | EASY 오른쪽 / PRO 인스펙터 > 모션 속도 |

속도 슬라이더는 문서 전체의 재생 시간을 정합니다. 느리게 하면 실제로 길어지고
프레임 수도 늘어납니다. 그래서 오브제를 여럿 올려 둔 화면에서 하나만 빠르게 하려고
이 슬라이더를 끌면 **모든 것이 함께 빨라지고 프레임 수까지 바뀝니다.**

`이 오브제만 빠르게` 는 그 반대입니다. 전체 길이도 초당 프레임도 한 글자도 건드리지
않고, 고른 오브제만 같은 길이 안에서 여러 바퀴 돕니다. 배경은 천천히 흐르고 앞의
아이콘만 빠르게 튀는 그림이 이렇게 만들어집니다.

**정수 배로만 올라갑니다** (2 / 3 / 4 / 6 / 8 / 12배). 반복 재생의 이음새 때문입니다.
한 바퀴가 전체 길이를 정확히 나누어야 마지막 바퀴가 잘리지 않고, 잘리면 지금까지
매끈하던 모션에 매 바퀴 튀는 자리가 새로 생깁니다.

타임라인과 그래프 에디터에는 **한 바퀴만** 그려집니다. 키프레임은 원래 자리에
그대로 있고 재생만 여러 번 도는 것이라, 배수를 1배로 되돌리면 손댄 것 없이 원래
모션으로 돌아옵니다. 레이어 목록의 이름 옆에 `3배` 처럼 표시가 붙습니다.

전체 길이가 짧으면 배수도 그만큼만 걸립니다. 한 바퀴는 최소 두 프레임이 있어야
정수 프레임 격자에서 모양이 남기 때문입니다.

## 타임라인 (전체 표시)

타임라인은 두 층입니다.

| 층 | 무엇이 있는가 |
| --- | --- |
| 위 · 클립 | **문서의 모든 레이어**가 한 줄씩. 막대가 그 레이어가 보이는 구간입니다 |
| 아래 · 속성 | 지금 고른 레이어 하나의 트랙과 키프레임 |

두 층의 시간축은 하나입니다. 확대하거나 밀면 함께 움직이고 재생 헤드도 하나입니다.

### 구간 (있다 없다)

막대가 곧 "이 레이어가 언제 있는가" 입니다.

| 하고 싶은 것 | 조작 |
| --- | --- |
| 통째로 옮기기 | 막대 **가운데**를 끕니다 |
| 길이 바꾸기 | 막대 **양끝**을 끕니다 |
| 구간 만들기 | 점선 막대(구간 없음)의 양끝을 끌거나, 줄을 더블클릭합니다 |
| 구간 없애기 | 구간이 있는 줄을 더블클릭하거나 `구간 해제` |
| 재생 헤드에 맞추기 | `시작 [` / `끝 ]` (단축키 `[` `]`) |
| 레이어 목록에서 끌어오기 | 왼쪽 손잡이를 잡고 **타임라인 위로** 끌고 가서 놓습니다 |

- 여러 장을 골라 두면 **함께 움직입니다.** 서로의 간격이 그대로 유지되고, 한 장이
  끝에 닿으면 전부 함께 멈춥니다
- **점선 막대**는 구간이 없다는 뜻입니다. 처음부터 끝까지 보이고, 전체 길이를 바꾸면
  따라 늘어납니다. 실선 막대는 그 자리에 남습니다
- 잠긴 레이어는 고를 수는 있어도 끌리지 않습니다
- 키보드로도 됩니다. 타임라인에 Tab 으로 들어가면 구간 목록이 뜨고, 좌우 화살표로
  한 프레임씩(Shift 는 10) 밀고 `[` `]` 로 재생 헤드에 맞추고 Delete 로 해제합니다

### 그림 바꿔 끼우기 (눈 깜빡임)

눈뜬 / 반눈 / 감은 그림 세 장을 딱딱 바꿔 끼우는 편집입니다.

1. 세 장을 전부 넣습니다 (`Ctrl+V` 로 하나씩 붙여넣어도 됩니다)
2. 레이어 목록이나 타임라인에서 **Ctrl 클릭으로 세 장을 다 고릅니다.**
   고른 순서가 아니라 **목록에 보이는 순서(위가 먼저)** 대로 나뉩니다
3. `차례로 나누기` 를 누릅니다

전체 길이가 셋으로 나뉘고 각자 자기 토막에만 있습니다. 한 프레임도 겹치지 않고
사이도 비지 않습니다. **페이드를 만들지 않으므로 서서히 바뀌지 않고 딱 넘어갑니다.**

깜빡임 리듬을 손보려면 막대 끝을 끌어 길이를 바꾸면 됩니다. 눈뜬 상태를 길게 두고
반눈과 감은 상태를 두어 프레임씩만 두면 사람 눈처럼 보입니다. 감았다 뜨는 것까지
넣으려면 반눈을 한 장 더 복제해 감은 그림 뒤에 놓으세요.

프레임이 고른 장 수보다 적으면 만들 수 있는 만큼만 나누고 그 사실을 알려 줍니다.
그때는 전체 길이를 늘리세요.

## 컷 편집

왼쪽 패널의 `컷` 탭입니다. 컷은 별도의 파일이 아니라 **한 타임라인을 나눈 구간**입니다.
그래서 컷을 써도 그래프 에디터와 모션 프리셋이 지금까지와 똑같이 동작합니다.

1. `컷 추가` 로 컷을 만듭니다. 전체 길이가 그만큼 늘어납니다
2. 레이어를 고르고 `이 컷에 넣기` 를 누릅니다
3. `앞 컷과 겹침` 을 올리면 그만큼 앞 컷이 사라지며 뒤 컷이 떠오릅니다. 0 이면 딱 잘립니다

컷에 넣지 않은 레이어는 **모든 컷에서 계속 보입니다.** 로고나 배경처럼 끝까지 남아야
하는 것을 그대로 두면 됩니다.

## 가리기

그림을 옮기거나 흐리게 하는 대신 **경계선이 지나가게** 합니다. 실제 방송 자막과
컷인이 거의 전부 이 방식입니다.

PRO 의 인스펙터 > 가리기에서 모양을 고릅니다.

| 모양 | 어떻게 지나가는가 |
| --- | --- |
| 왼쪽 / 오른쪽 / 위 / 아래에서 | 한쪽 끝에서 반대쪽으로 쓸고 지나갑니다 |
| 가운데에서 좌우로 / 위아래로 | 양문이 열리듯 갈라집니다 |
| 가운데에서 원으로 | 동그란 구멍이 자랍니다 |
| 시계 방향으로 | 열두 시부터 한 바퀴 돕니다 |
| 블라인드 | 가로 칸마다 따로 열립니다 |
| 잉크처럼 번지며 | 얼룩이 번지듯 경계가 들쭉날쭉하게 자랍니다 |
| 부채처럼 펼쳐지며 | **아래 변의 가운데**를 축으로 반 바퀴만 펼쳐집니다 |

`잉크처럼 번지며` 는 원이 자라는 것과 뼈대가 같고 경계만 다릅니다. `얼룩 잘기` 를
올리면 잘게 갈라집니다. 노이즈만으로 만들면 얼룩이 온 화면에 **동시에** 피어올라
번지는 것으로 안 보여서, 반지름을 뼈대로 깔고 노이즈를 45%만 섞습니다.

`부채처럼 펼쳐지며` 는 `시계 방향으로` 와 다릅니다. 시계는 **한복판**을 돌고 한
바퀴를 채우지만, 부채는 **아래 변의 가운데**를 돌고 반 바퀴만 씁니다. 부채도
아치도 무지개도 손잡이가 그림 한복판에 있지 않습니다. 한복판을 돌리면 아래쪽
절반이 먼저 열려서 "펼쳐진다" 가 아니라 "돌아간다" 로 보입니다.

`경계 흐림` 이 0 이면 칼로 자른 듯 끊기고, 올리면 스며들듯 드러납니다.
진행률 0 과 1 에서는 흐림과 무관하게 **완전히 가려지고 완전히 보입니다.**

`반대로 뒤집기` 는 경계선이 **어느 쪽에서 오는지**를 바꿉니다. 되감기가 아닙니다.
거꾸로 재생하고 싶으면 진행률 트랙을 1 에서 0 으로 찍으면 됩니다.

진행률은 별도의 트랙입니다. 스톱워치를 켜면 타임라인에서 시간에 따라 밀 수 있고,
그래프 에디터로 가속·감속을 넣을 수도 있습니다.

**테두리만 남긴 도형에 `시계 방향` 을 걸면 선이 그려집니다.** 도형 세트의
`네모 테두리 그려지기` 와 `바람개비 살` 이 이 방식입니다.

경계선은 레이어를 따라 돕니다. 카드를 45도 기울이면 경계선도 같이 기울어집니다.

## 입체 뒤집기

`세로축 회전` 은 카드가 좌우로 도는 것이고, `가로축 회전` 은 종이가 앞뒤로 눕는
것입니다. 인스펙터 > 레이어에 있고, 다른 값과 똑같이 스톱워치를 켜서 애니메이션할
수 있습니다.

**진짜 원근이 걸립니다.** 가로 폭을 눌러 흉내내는 방식이 아니라, 가까운 변이
커지고 먼 변이 작아지는 사다리꼴이 나옵니다.

`원근 거리` 는 레이어 긴 변의 몇 배만큼 떨어져서 보는가입니다. 작을수록 원근이
세고, 0 이면 원근 없이 각도만큼만 눌립니다. px 가 아니라 배수인 이유는 캔버스
크기를 바꿔도 같은 그림이 나와야 하기 때문입니다.

프리셋으로는 `카드 뒤집으며 등장` / `종이 펼치며 등장` / `카드 뒤집으며 사라짐` /
`카드 한 바퀴` / `입체로 기울이기` / `경첩 열리며 등장` 여섯 가지가 있습니다.

### 경첩

`경첩 열리며 등장` 은 **고정되는 변이 한 픽셀도 움직이지 않습니다.** 위 / 아래 /
왼쪽 / 오른쪽 중 하나를 고르면 그 변이 축이 되어 문처럼 젖혀집니다. 봉투 뚜껑,
여닫이문, 병풍이 전부 이 모양입니다.

`종이 펼치며 등장` 과 다릅니다. 저쪽은 **한복판**을 축으로 눕혔다 세우고 어긋나는
자리를 세로 이동으로 어림해 메웁니다. 원근이 걸리면 그 방법은 성립하지 않습니다.
각 점의 깊이가 달라서, 원근 나눗셈 뒤에 어긋난 자리를 평행이동 하나로 되돌릴 수
없기 때문입니다.

그래서 이 프리셋만 **기준점을 옮깁니다.** 다른 프리셋으로 갈아타면 한가운데로
돌아가고, 인스펙터에서 손으로 옮겨 둔 기준점은 그대로 살아남습니다.

## 모션 기준점

회전과 확대가 도는 축입니다. EASY 는 `빠른 설정`, PRO 는 인스펙터 > 레이어에서
3x3 으로 고릅니다.

기준점을 옮겨도 **그림이 놓이는 자리는 바뀌지 않습니다.** 캔버스(자른 상태라면
자른 크기)의 한가운데를 기준으로, 도는 축만 옮겨집니다. 왼쪽 위를 고르면
왼쪽 위 모서리가 박힌 채로 회전하고, 확대도 그쪽에서 자랍니다.

## 캔버스에서 끌어 옮기기

미리보기 위의 그림을 그냥 끌면 자리가 바뀝니다. 숫자로 맞추고 싶으면 인스펙터의
`위치 X` / `위치 Y` 를 쓰면 됩니다. 둘은 같은 값을 만집니다.

**무엇이 움직이는지는 지금 고른 것이 정합니다.**

| 상황 | 움직이는 것 |
| --- | --- |
| 그냥 끌기 | 누른 자리의 맨 위 레이어 (그 레이어가 선택됩니다) |
| 그 레이어를 담은 **폴더**를 골라 둔 상태 | 폴더째. 안의 식구가 전부 함께 갑니다 |
| 여러 장을 골라 둔 상태에서 그중 하나를 끌기 | 고른 것 전부. 서로의 간격은 그대로입니다 |
| `Alt` 를 누른 채 끌기 | 폴더를 골라 뒀어도 누른 레이어 한 장만 |

- 폴더가 돌아가 있거나 확대되어 있어도 **그림은 손을 따라옵니다.** 폴더 좌표계로
  되돌려서 값을 쓰기 때문입니다
- **잠긴 레이어는 움직이지 않고, 눌러도 잡히지 않습니다.** 위에 잠긴 레이어가
  덮여 있어도 그 아래 것을 바로 잡을 수 있습니다
- 위치에 키프레임을 찍어 둔 레이어를 끌면 **재생 헤드가 있는 프레임에 키가
  생깁니다.** 아니면 그냥 그 자리가 바뀝니다
- 한 번의 드래그는 **`Ctrl+Z` 한 칸**입니다. 여러 장을 함께 옮겨도 한 칸입니다
- 선택한 것에는 흰 파선 테두리가 뜹니다. 재생 중에는 그리지 않습니다

## 격자

미리보기 아래 `격자` 버튼(단축키 `Ctrl+'`)으로 켭니다. 칸은 8 / 16 / 32 / 64px 중에
고릅니다. 캔버스 픽셀 기준이라 화면 배율을 바꿔도 격자가 가리키는 자리는 같습니다.

**켜져 있으면 끌어 옮길 때 칸에 딱 붙습니다.** 붙는 기준은 그림의 한가운데이고,
격자는 캔버스 왼쪽 위(0, 0)에서 시작합니다. 네 칸마다 굵은 선이 들어가 눈으로
세기 쉽습니다.

여러 장을 함께 끌 때는 **직접 잡은 한 장만** 칸에 붙고, 나머지는 그 장이 실제로
움직인 만큼 따라갑니다. 각자 붙이면 맞춰 둔 간격이 옮기기만 해도 무너집니다.

격자는 화면에만 있습니다. 결과 파일에는 한 픽셀도 나가지 않고, 프로젝트에
저장되지도 않습니다.

## 레이어 창

- 레이어 목록과 모션 프리셋 사이의 **손잡이를 끌면** 목록 높이가 바뀝니다.
  두 번 누르면 기본 높이로 돌아갑니다. 키보드는 손잡이에 포커스를 준 뒤
  위/아래 화살표(Shift 를 누르면 3배), `Home` / `End` 를 씁니다.
  정한 높이는 브라우저에 남아 다음에 열 때도 그대로입니다
- 패널 머리의 눈 아이콘은 **전체 숨기기 / 전체 보이기**, 자물쇠 아이콘은
  **전체 잠그기 / 전체 잠금 풀기** 입니다. 몇 장이든 한 번의 `Ctrl+Z` 로 되돌아갑니다
- 여러 장을 골라 지워도 **`Ctrl+Z` 한 번**이면 전부 돌아옵니다
- 행의 단추는 왼쪽부터 **눈**(숨기기) · **가위**(아래 모양으로 자르기) ·
  **자물쇠**(잠그기) · **휴지통**입니다. 키보드로는 `Space` `C` `L` `Delete` 입니다
- 왼쪽 **손잡이**를 끌면 순서가 바뀝니다. 그대로 **아래 타임라인까지 끌고 가면**
  순서 대신 그 프레임부터 보이도록 구간이 놓입니다

## 레이어 폴더

패널 머리의 폴더 아이콘을 누르면 폴더가 생깁니다. 레이어를 고른 상태로 누르면
그것들을 담은 폴더가 만들어집니다. 목록에서 폴더 안으로 끌어다 놓아도 됩니다.

**폴더 머리행은 식구들 위에 옵니다.** 포토샵과 피그마와 같습니다. 문서 배열은
폴더가 식구보다 뒤쪽(z 가 낮은 쪽)에 있어서 그냥 뒤집으면 머리행이 아래로
내려가는데, 그러면 어느 줄이 무엇에 속하는지 읽히지 않습니다.

**폴더 앞의 삼각형으로 접습니다** (키보드는 `←` `→`). 접으면 식구가 목록에서
사라지고 이름 옆에 몇 장인지 숫자가 붙습니다. 접은 상태로 끌어다 놓으면 폴더가
통째로 움직이고, 접힌 폴더 위에 다른 레이어를 놓아도 안으로 빨려 들어가지 않습니다.

**폴더를 지우면 안에 든 것도 함께 지워집니다.** 몇 겹으로 중첩돼 있어도 전부
따라갑니다. 목록에서 한 줄로 보이는 것이 화면에서도 한 덩어리이기 때문입니다.
삭제 버튼에 몇 장이 함께 지워지는지 표시되고, **`Ctrl+Z` 한 번**이면 폴더와 식구가
통째로 돌아옵니다. 상자만 없애고 안은 남기고 싶으면 지우기 전에 목록에서 밖으로
끌어내면 됩니다.

**폴더의 움직임과 안쪽의 움직임이 함께 보입니다.** 사진에 `톡 튀며 등장`을 걸고,
그 사진을 담은 폴더에 `천천히 확대`를 걸면 둘이 겹쳐서 나옵니다. 폴더는
아무것도 그리지 않고 자기 좌표계만 안쪽에 얹기 때문입니다.

| 폴더가 물려주는 것 | 물려주지 않는 것 |
| --- | --- |
| 이동 / 회전 / 배율 / 기울임 | 픽셀 (폴더는 그리는 것이 없습니다) |
| 투명도 / 숨김 / 구간(컷) | 가리기 / 효과 (안쪽 레이어에 각자 겁니다) |

`깊이감`(레이어 관계의 부모)과 다릅니다. 깊이감은 **이동만** 그것도 비율을 곱해
물려받아 배경이 인물보다 조금만 움직이는 그림을 만듭니다. 폴더는 좌표계째로
물려받아서, 폴더를 반으로 줄이면 안쪽 레이어의 **위치까지** 반으로 당겨집니다.

도형 세트는 **폴더에 담겨, 접힌 채로 나옵니다.** 세트 하나가 도형을 스무 장까지
만드는데 펼쳐져 있으면 폴더 한 줄이 그냥 덧붙을 뿐입니다. 접혀 있으면 목록에
한 줄이고, 그 한 줄에 모션을 걸면 세트 전체가 함께 움직입니다.

움직이는 폴더 안에서는 `채우기`가 동작하지 않습니다. 폴더가 그룹째로 움직이면
한 장만 보고 푼 배율이 맞지 않아서, 틀린 배율로 개입하느니 빠지는 편이 낫습니다.
`담기`는 폴더를 그대로 반영하므로 영향이 없습니다.

## 아래 모양으로 자르기 (클리핑)

켜는 곳은 두 군데입니다.

- 레이어 목록의 **가위 단추**. 행에 마우스를 올리면 눈 / 가위 / 자물쇠 / 휴지통이 보입니다
- 인스펙터 > 레이어 관계의 `아래 모양으로 자르기`

행에 포커스를 두고 `C` 를 눌러도 됩니다. **폴더 행에서도 똑같이 켜집니다.**

켜면 그 레이어는 **바로 아래 레이어가 그린 자리에만** 보입니다. 사진을 글자 모양으로 자르거나 무늬를 도형 안에만
채울 때 씁니다. 목록에서는 왼쪽에 갈고리 표시가 붙습니다.

기준은 아래 레이어의 **알파**입니다. 색이 아닙니다. 그래서 반투명한 가장자리는
반투명하게 잘리고 글자의 매끄러운 곡선이 그대로 살아납니다.

- 여러 장을 연달아 켜면 **전부 같은 밑판**을 씁니다. 위에서부터 물려받지 않습니다
- 밑판은 **같은 폴더 안에서** 찾습니다. 폴더 경계를 넘지 않습니다
- 밑판에 건 모션이 움직이면 잘리는 모양도 함께 움직입니다

**폴더도 자르고 폴더로도 자릅니다.**

- 폴더가 잘리는 쪽이면 **폴더 안의 그림 전체**가 한 장처럼 잘립니다
- 폴더가 밑판이면 **폴더 안의 그림 전체가 모양**이 됩니다. 도형 여러 장으로 만든
  모양 안에만 사진을 채울 때 이렇게 씁니다

밑판은 배열에서 바로 앞이 아니라 **바로 앞 형제**입니다. 앞 형제가 폴더면 그
폴더의 식구가 사이에 끼어 있는데, 그것들은 남의 집 안이라 건너뜁니다.

## 그라데이션과 흐림

인스펙터 > 효과에서 얹습니다.

`그라데이션` 의 섞는 방식이 **색만 바꾸기**면 알파(실루엣)는 그대로 두고 색만
갈아치웁니다. 별 모양 도형에 걸면 별이 그라데이션으로 칠해지고, 글자에 걸면
글자가 칠해집니다. 사진에는 `곱하기` 나 `겹치기` 로 노을빛을 입힙니다.
각도와 위치에 스톱워치를 켜면 그라데이션이 흐릅니다.

`부드러운 흐림` 은 사방으로 고르게 번집니다. 반경을 크게 하면 **표본 수도 올려야**
깔끔합니다. 표본이 모자라면 겹친 그림자처럼 갈라져 보입니다.

`렌즈 색수차` 는 `RGB 분리` 와 다릅니다. RGB 분리는 화면 전체를 같은 방향으로 민
고장난 신호이고, 렌즈 색수차는 **가운데는 또렷하고 가장자리로 갈수록** 색이
갈라지는 광학 현상입니다. 사진처럼 보이게 하려면 이쪽입니다.

### 광택 / 번지는 빛 / 잔상

셋 다 밝기나 사본을 더하는데, 알파를 대하는 태도가 다릅니다. 그 차이가 셋의
정체입니다.

`광택 훑기` 는 밝은 띠가 표면을 사선으로 지나갑니다. **알파를 손대지 않아서**
그려진 자리 안에서만 빛납니다. 빛줄기를 도형 한 장으로 얹으면 부채나 배지나 글자
같은 네모가 아닌 것 위에서 실루엣 밖으로 삐져나갑니다. `위치` 에 스톱워치를 켜고
0 에서 1 로 밀면 한 번 훑고 지나갑니다. 프리셋 `광택 내며 등장` 이 그 한 벌입니다.

`번지는 빛` 은 **문턱을 넘은 밝은 곳만** 뽑아 흐린 뒤 되더합니다. `부드러운 흐림`
은 그림 전체를 뭉개지만 이쪽은 형태를 또렷하게 둔 채 주위만 환하게 만듭니다.
빛은 물체 **밖으로** 번져야 빛으로 보이므로 알파를 늘립니다. 번진 빛의 알파는
원본 알파를 흐린 값이 상한이라, 투명 배경이 통째로 불투명해지는 일은 없습니다.

`잔상 겹치기` 는 같은 그림을 한 방향으로 밀어 **뒤에** 여러 겹 깝니다. 방향성
블러가 매끄럽게 뭉개는 것과 달리 사본 한 장 한 장이 보입니다. 빠르게 미끄러지는
글자 뒤에 남는 것은 뭉개진 얼룩이 아니라 옅어지는 사본들입니다.

### 효과와 모션 옮기기

한 오브제에 맞춰 둔 움직임과 효과를 다른 오브제로 그대로 보냅니다. 같은 프리셋을
다시 고르고 세기와 속도를 다시 맞추는 대신, **눈으로 확인한 그 모션 그대로** 갑니다.

PRO 인스펙터 > `모션 옮기기` 에서 보낼 곳을 고르고 누릅니다.

| 하고 싶은 것 | 조작 |
| --- | --- |
| 사본만 보내기 | `복사해서 넣기`. 원본은 그대로입니다 |
| 통째로 넘기기 | `옮기기 (여기서 빼기)`. 원본에서는 빠집니다 |
| 일부만 보내기 | 체크로 갈래를 고릅니다 |

갈래는 셋입니다. `움직임`(키프레임 · 흔들림 · 모션 배수), `효과`(효과 스택),
`가리기 · 등장 · 기준점`. 효과만 가져오고 움직임은 각자 두는 것이 흔한 쓰임새입니다.

EASY 에는 `지금 모션을 나머지 오브제에도` 한 줄로 있습니다. 고른 오브제의 모션을
나머지 전부에 똑같이 넣습니다.

**따라가지 않는 것**: 이름 · 그림 · 크기 · 맞춤 · 혼합 · 보이는 구간 · 담기 배율.
담기 배율은 그 오브제의 픽셀 크기를 기준으로 푼 값이라 크기가 다른 곳에 심으면
이유 없이 작아집니다. 받은 쪽에서는 지우고 문서에서 다시 풉니다.

폴더에 보내면 움직임만 걸립니다. 폴더는 그릴 픽셀이 없어 효과와 가리기를 지울
화면 자체가 없기 때문입니다. 폴더가 움직이면 안에 든 오브제가 함께 갑니다.

받은 쪽의 모션은 그때부터 **사용자가 직접 만든 모션**으로 취급됩니다. 그래서 EASY 의
세기와 속도 슬라이더는 원본 오브제에만 걸리고, 받은 쪽은 보낸 시점 그대로 남습니다.

## 자르기

EASY 모드에는 두 가지가 있습니다.

- `빈 여백 잘라내기` 는 그림 둘레의 투명하거나 단색인 여백을 찾아 한 번에
  잘라냅니다. `원래대로` 로 되돌립니다
- `직접 자르기` 는 창을 열어 **남길 영역을 직접 끕니다.** 기본은 비율 자유이고,
  1:1 같은 고정 비율도 고를 수 있습니다. `원본으로 되돌리기` 가 창 안에 있습니다

PRO 모드는 인스펙터 > 이미지 다듬기에서 같은 일을 합니다.

| 하고 싶은 것 | 방법 |
| --- | --- |
| 자유롭게 자르기 | 비율에서 `자유` 를 고릅니다 (기본값) |
| 새로 그리기 | 미리보기 빈 곳을 끕니다 |
| 옮기기 | 상자 안쪽을 끕니다 |
| 크기 바꾸기 | 모서리나 변의 핸들을 끕니다 |
| 비율 고정 | `1:1` `4:5` `3:4` `16:9` `9:16` 중 하나를 누릅니다 |
| 1px 단위로 맞추기 | X / Y / 폭 / 높이 숫자 칸을 씁니다 |

`캔버스도 자른 크기에 맞추기` 를 끄면 잘라낸 여백이 프레임의 빈 공간으로
남습니다. 켜 두는 편이 대부분 맞습니다.

## 내보내기

### 돌리기와 뒤집기

내보내기 창의 `방향` 에서 **결과 파일 자체**를 돌립니다. 오른쪽 90도 / 180도 /
왼쪽 90도, 그리고 좌우 · 상하 뒤집기입니다. 세로로 찍은 그림을 가로로 눕혀 내보낼 때
캔버스를 다시 짜지 않아도 됩니다.

90도와 왼쪽 90도에서는 **가로세로가 바뀝니다.** 512 x 256 캔버스는 256 x 512 파일이
됩니다. 예상 결과와 파일 이름이 그 크기를 씁니다.

**화질은 한 픽셀도 상하지 않습니다.** 90의 배수 회전과 반전은 픽셀 자리를 바꾸는
것뿐이라 색이 섞이지 않습니다. 비스듬한 각도는 여기 없습니다. 그건 리샘플링이라
가장자리가 뭉개지므로, 레이어 회전으로 만들고 그대로 내보내는 쪽이 맞습니다.

### 용량 다이어트

해상도도 프레임 수도 색상 수도 줄이지 않고 파일만 줄이는 두 가지입니다.

**움직임 없는 곳 얼리기.** 파일이 커지는 가장 큰 원인은 눈에 안 보이는 미세한 색
흔들림입니다. 사진의 알갱이, 그라데이션의 디더 잡티, 이전 압축의 잔여물이 프레임마다
1~2씩 흔들립니다. 사람 눈에는 정지 화면인데 코덱에게는 전 화면이 바뀐 프레임입니다.
이 값보다 가까운 픽셀은 **다시 그리지 않습니다.** APNG 는 바뀐 사각형이 좁아지고,
GIF 는 같은 색이 길게 이어져 압축이 짧아집니다.

비교 대상이 "직전 프레임" 이 아니라 **"지금 화면에 찍혀 있는 값"** 입니다. 그래서
오차가 쌓이지 않습니다. 아무리 오래 얼어 있어도 참값과의 거리가 언제나 임계값
안이고, 벗어나는 순간 다시 그려집니다. 권장값은 16 이고 `알아서` 버튼이 그 값을 넣습니다.

**그레인 먼저 걷어내기.** 알갱이를 미리 지우고 그 비트를 선과 글자에 씁니다. 세부가
약한 곳만 뭉개고 또렷한 경계는 한 값도 건드리지 않습니다. 얼리기와 함께 쓰면 훨씬
잘 듭니다. 알갱이가 남아 있으면 거의 모든 픽셀이 임계값을 넘겨 얼릴 것이 없기
때문입니다. 대신 프레임마다 한 번씩 더 계산하므로 조금 느려집니다.

### 목표 용량 맞추기

`이 크기 이하로 맞춰 주세요` 에 숫자를 넣고 `맞춰보기` 를 누르면 도구가 알아서
조정합니다. 조정 순서는 **눈에 덜 띄는 것부터**입니다.

| 순서 | 무엇을 | 무엇이 남는가 |
| --- | --- | --- |
| 1 | 얼리기 | 해상도 · 프레임 · 색상 전부 그대로 |
| 2 | 해상도 | 프레임 수와 색상은 그대로 |
| 3 | 프레임 수 (fps) | 재생 시간은 그대로 |
| 4 | 화질 (WebP) | 크기와 프레임 수는 그대로 |
| 5 | 색상 수와 디더 (GIF) | |

무엇을 얼마나 줄였는지 조정 전후 표로 보여 주고, **마음에 들 때만** 적용합니다.
5MB 같은 업로드 제한에 맞출 때 여기에 숫자를 넣으면 됩니다.

## 크기와 용량

- 캔버스 상한은 **4000px** 입니다. 저사양 기기의 텍스처 상한(4096px) 아래로
  잡은 값입니다
- 큰 캔버스는 프레임을 렌더하는 즉시 인코딩해서 버리는 **스트리밍 경로**로
  갑니다. 원시 프레임을 전부 들고 있지 않으므로 4000px 도 만들 수 있습니다
- 만들어지는 파일이 **2GB** 를 넘으면 이유를 알리고 중단합니다. 크기를 한 단계
  줄이거나 속도를 올려(길이가 짧아집니다) 다시 시도하세요

## 브라우저

WebGL2 를 쓰므로 최신 Chrome / Edge / Firefox / Safari 에서 동작합니다.
APNG 와 WebP 는 브라우저마다 지원이 갈리는데, 내보내기 화면의 진단 패널이
이 브라우저에서 직접 재서 알려 줍니다.

## 개발

```bash
npm install
npm run dev
```

| 명령 | 하는 일 |
| --- | --- |
| `npm run dev` | 개발 서버 |
| `npm run build` | 타입 검사 후 빌드 |
| `npm test` | 테스트 |
| `npm run preview` | 빌드 결과 미리보기 |

Windows 에서는 `모션메이커 실행.cmd` 를 더블클릭해도 됩니다.
`바탕화면 바로가기 만들기.cmd` 를 한 번 실행하면 바탕화면에 아이콘이 생깁니다.

## 배포

`main` 브랜치에 밀어 넣으면 GitHub Actions 가 빌드해서 GitHub Pages 로 올립니다
(`.github/workflows/deploy.yml`).

저장소 이름은 워크플로가 빌드할 때 넣어 주므로 설정 파일에 적어 둘 필요가 없습니다.
저장소 이름을 바꿔도 그대로 동작합니다.
